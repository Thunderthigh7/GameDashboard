First-run setup

Complete these once per Roblox game before judging the dashboard.

  1. Sign in with Roblox

    Use the Roblox account that owns the game.

  2. Connect a game

    Pick one owned public game from the list.

  3. Install the secret

    Paste the generated secret into Settings.Secret in Roblox.

  4. Start a live server

    Join the game so the analytics heartbeat can send data.

  5. Confirm signals

    Movement, deaths, leaves, or chat should become active.

  6. Upload map

    Upload a map snapshot so heatmaps are readable.
