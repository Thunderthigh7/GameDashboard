Turn event data into answers.
Improve your game.

Sign in with the account that owns your game. Install one server service. Start seeing live player behavior.

Official Roblox OAuth

Roblox handles sign-in. RoAnalytics never asks for your Roblox password or private account details.

We only confirm the account and that it owns the game.
Why RoAnalytics?

Roblox tells you what happened.
RoAnalytics helps you understand why.

Roblox gives you the foundation for tracking events and funnels. RoAnalytics turns that data into something you can investigate, compare, map, and act on—without republishing your game every time you have a new question.

What you can do Roblox built-in analyticsRoblox RoAnalytics
Track custom gameplay events✓✓
View basic funnel reports✓✓
Turn any tracked events into a funnel, in any order, anytime—without republishing×✓
Compare properties across occurrences of the same event×✓
Compare events and funnels between game versions×✓
See where events happened directly on your game map×✓

RoAnalytics is built for custom player-behavior analytics—custom events, flexible funnels, and map activity. Use it alongside Roblox Analytics for CCU, retention, acquisition, and monetization, etc.

How it works

Set up RoAnalytics in four steps.

01

Log in through Roblox

Continue with Roblox using the account that owns the game or group.

Official Roblox OAuth
02

Choose your experience

Pick your game. RoAnalytics verifies ownership and creates its secret.

Public games · Multiple games supported
03

Install the server service

Add RoAnalytics to ServerScriptService. Paste the secret into Config/Settings.lua.

Studio or Rojo · Server-side only
04

Publish and play

Join the published game. Live analytics appear automatically.
